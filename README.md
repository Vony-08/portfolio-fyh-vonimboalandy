# Portfolio — Développeur Front-End / Intégrateur Web

Portfolio statique en HTML, CSS et JavaScript, conçu pour être publié gratuitement avec GitHub Pages.

## Fichiers

- `index.html` : contenu et sections du portfolio.
- `style.css` : design responsive clair.
- `script.js` : menu mobile et année automatique.
- `README.md` : ce guide.
- `assets/portrait.jpg` : photo utilisée dans la section d’accueil.
- `assets/logo-v-fyh.png` : logo V-FYH noir et doré extrait de la maquette fournie.

## Avant la publication

1. Vérifiez les coordonnées affichées dans la section Contact : e-mail, téléphone, LinkedIn et GitHub.
2. Le profil GitHub a été configuré à partir du pseudo visible sur votre capture : `Vony-08`. Vérifiez que l’adresse `https://github.com/Vony-08` ouvre bien votre profil.
3. Vérifiez le nom affiché, les dates et les descriptions du parcours.
4. Les trois projets sont présentés comme des **concepts à réaliser**. Gardez cette précision tant que vous n'avez pas terminé les projets et ajouté des captures/liens réels.


## Tester en local

Double-cliquez sur `index.html` pour l'ouvrir dans votre navigateur. Pour travailler confortablement, vous pouvez ouvrir le dossier dans VS Code et utiliser l'extension Live Server.

## Publier avec GitHub Pages (gratuit)

1. Connectez-vous à https://github.com/.
2. Cliquez sur **New repository**.
3. Nommez le dépôt `portfolio-integrateur-web`.
4. Choisissez **Public** (nécessaire avec GitHub Free pour cette méthode) et cliquez sur **Create repository**.
5. Dans le dépôt, utilisez **Add file → Upload files**.
6. Décompressez l'archive sur votre ordinateur, puis glissez-déposez les fichiers `index.html`, `style.css`, `script.js`, `README.md` et le dossier `assets` dans la page GitHub (pas le dossier parent compressé).
7. Cliquez sur **Commit changes**.
8. Ouvrez **Settings → Pages**.
9. Dans **Build and deployment**, choisissez **Deploy from a branch**.
10. Choisissez la branche `main`, le dossier `/(root)`, puis **Save**.
11. Attendez la fin du déploiement, puis ouvrez l'adresse affichée dans **Settings → Pages**. Elle ressemblera à `https://VOTRE-PSEUDO.github.io/portfolio-integrateur-web/`.

Les modifications suivantes seront publiées lorsque vous les commiterez dans la branche choisie. La publication peut prendre quelques minutes.

## Important

GitHub Pages héberge des fichiers statiques. Il ne fait pas tourner directement PHP, WordPress ou PrestaShop. Le portfolio peut présenter ces compétences et montrer des maquettes ou captures de projets réalisés séparément sur un environnement compatible.
